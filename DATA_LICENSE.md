# Data license scope and status

The root MIT License applies to the team's code, authored documentation and CRUNCH model weights. It does **not** grant new rights in third-party field labels, imagery-derived observations or upstream source material.

| Included component | Provenance | License evidence available for this release |
|---|---|---|
| WA field labels | Lower Yakima GWMA / WSDA and producer records | The local source bundle identifies the public layer but does not contain an explicit redistribution license. Status is unconfirmed; this release does not assert MIT coverage. |
| WA field-level index observations | Frozen summaries derived from Landsat imagery | Derived observations are included for reproducibility; upstream imagery terms and attribution remain applicable. This package does not supply raw imagery. |
| MD labels and field-level index observations | User-provided Hack the Harvest / USDA BARC competition snapshot | An explicit license for this exact competition subset was not present in the inspected local material. Do not infer its license solely from another USDA archive or from a public resources page. |

The source datasets are included as requested for reproducibility, with labels and provenance retained. This local release does not claim that all third-party redistribution permissions have been verified. A public publisher should resolve the two unconfirmed label-source statuses with the corresponding providers and add the actual license evidence. No blanket data-license assurance is implied by the repository's MIT code license.

See also [dataset documentation](docs/DATASET.md). Source hashes identify the precise local inputs used for packaging; a hash is not a license grant.
